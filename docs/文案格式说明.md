# 文案 md 格式说明

`batch_copy_to_draft.py --copy` 读取的文案文件格式。每条文案一个 `###` 块：

```markdown
### 1｜A30 身份认同＋款式设计＋功效性能＋人群｜季节钩

怕黑围巾显老的人，看这条。曜石黑底上晕开水墨山脊，远看是黑，
近看全是层次。100%桑蚕丝贴脖细滑不扎，戴上气场一下就稳了。

- 格子落点：身份认同→怕黑显老的人；款式设计→水墨山脊纹；功效性能→贴脖细滑不扎；人群→秋冬要气场的人
- 素材：产品上身
```

## 解析规则

- 标题行：`### 数字｜公式｜钩子`（`｜` 或 `|` 都可）。公式取第一段，钩子取最后一段
- 正文：标题后到第一个 `- ` / 空行 / `#` 之前的所有行，拼成口播文本
- `- 格子落点：`：用 `→` 分隔，`；` 分隔多个。格子名决定取片文件夹：
  - 人群 / 戴法 / 身份认同 / 趋势风格 → `人物/`
  - 面料工艺 / 款式设计 / 颜色 / 对比 / 纹样叙事 → `细节/`
  - 穿着场合 / 场景 / 季节 → `氛围/`（没有则用人物的）
  - 每条第1段固定用 `开头/`
- 其余 `- ` 开头的行和 `---` 会被忽略

## 写作建议（配合本工具效果最好）

- 单条 65–80 字，约 20 秒口播
- 开头第一句圈定人群或场景，不要书面腔
- 人物格子只写通用上身镜头能承载的效果、氛围、情绪，不要写需要特定镜头的具体动作
- 每条只讲 1–2 个卖点，宁可拆条不堆料
