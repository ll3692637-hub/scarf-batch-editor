# 剪映批量口播视频生成器

把写好的口播文案，批量转成剪映专业版（5.6）可打开的草稿：自动分段、自动配字幕、自动匹配素材、AI 配音直铺、BGM 通铺。一次跑完 N 条 20 秒口播视频的初剪，打开剪映微调后直接导出。

## 工作原理

```
口播文案 md → 分段分镜 → 素材库轮询取片 → 豆包 TTS 配音 → 生成剪映草稿 → 剪映打开微调导出
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `batch_copy_to_draft.py` | 主入口：解析文案 md，分段，轮询取片，调配音，生成草稿 |
| `edl_to_draft.py` | 把分镜 EDL 转成剪映草稿目录结构（含字幕、配音轨、BGM） |
| `tts_doubao.py` | 豆包 Seed-TTS 配音：按完整语意段一次性合成，不断句 |
| `retime_to_vo.py` | 备用：无真音频时按字数预估时长（`--tts none` 模式用） |

## 快速开始

```bash
# 1. 准备
# - 素材库按 产品/开头|细节|人物|氛围 文件夹整理好
# - 文案 md 按 docs/文案格式说明.md 写
# - 彻底退出剪映（Cmd+Q），否则草稿目录被锁定

# 2. 配豆包 Key（配音用）
export DOUBAO_TTS_KEY='你的火山引擎语音合成 Key'

# 3. 跑批量
python3 batch_copy_to_draft.py \
  --copy copy/2026-10-05-产品A.md \
  --product 产品A \
  --lib ~/Movies/jianying_assets/素材库 \
  --tts doubao \
  --bgm ~/Movies/jianying_assets/bgm/bgm.mp3

# 4. 打开剪映，草稿列表里会出现 N 条，检查后导出
```

常用参数：`--start N` 从第 N 条开始，`--count N` 只跑 N 条，`--dry-run` 只打印取片计划不生成，`--tts edge` 用免费 edge-tts，`--tts none` 不配音（剪映里手动朗读）。

## 核心规则（写死在代码里）

- **配音铁律**：按完整语意段一次性送 TTS，一段一条连续音频；字幕只是显示切分，绝不逐条合成
- **分段**：长句按强标点（；：）拆句读，不拦腰切；每段 ≤2 行，每行 ≤16 字
- **取片**：第1段→开头文件夹；工艺浓度最高的不超过2段→细节；其余→人物；使用次数最少优先，时长最接近优先；可慢放但不低于 0.5x
- **字幕**：黑框白字，画面下 1/3；长字幕按自然停顿拆成 8–14 字短字幕轮播
- **去重**：按文件名去重，一条视频内不出现重复画面

## 环境要求

- macOS + 剪映专业版 5.6（草稿目录结构按 5.6 编写）
- Python 3.9+
- `pip install requests`（豆包配音用）
- ffprobe（取片时长探测用，`brew install ffmpeg`）
